# AI Dev Kit Installation

Use this repository as the shared development-workflow source for Today Weekly Release Company.

## Procedure

1. Clone this repository.
2. Open the repository root in Codex.
3. Use the Codex Skills picker to confirm that Codex discovers the skills in `.agents/skills/`.
4. Invoke a skill by name or let Codex select one from the task description.

## Verification

```bash
ls .agents/skills
```

Expected skills:

```text
code-review-excellence
pixelmatch-check
playwright-cli
```
